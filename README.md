# Character Trip — Personality Travel Matcher

Одностраничное адаптивное веб-приложение на HTML5, CSS3 и Vanilla JavaScript. В проекте нет сборщика, backend или внешних JS-библиотек: для запуска достаточно открыть `index.html` в браузере.

## Что реализовано

- Атмосферный полноэкранный hero с авторской SVG-сценой ночной долины и анимированными частицами, реагирующими на курсор.
- Адаптивная навигация, плавная прокрутка и анимации появления секций.
- Четыре направления: горы, море, лес и мегаполис.
- Ровно 20 вопросов, по четыре варианта ответа.
- Индикатор прогресса, переходы вперёд/назад, возможность поменять ответ.
- Подсчёт баллов по четырём направлениям и дополнительным характеристикам (социальность и активность).
- Персональный архетип, направление, длительность и активности; повторное прохождение и копирование результата.
- Мобильная версия и поддержка `prefers-reduced-motion`.

## Локальный запуск

Откройте `index.html` в Chrome, Edge, Firefox или Safari. Все иллюстрации находятся в папке `assets/` и подключаются относительными путями.

## Публикация через GitHub и Azure Static Web Apps

1. Создайте GitHub-репозиторий и загрузите в корень `index.html`, `README.md` и папку `assets/`.
2. В Azure Portal создайте ресурс **Static Web App**.
3. Выберите тариф Free, подключите GitHub-репозиторий и нужную ветку.
4. Для обычного статического сайта укажите:
   - Build Preset: **Custom**
   - App location: `/`
   - Api location: оставить пустым
   - Output location: `/`
5. Запустите создание ресурса. Azure добавит workflow в репозиторий и опубликует сайт.
6. После завершения GitHub Actions откройте публичный URL вида `https://<имя>.azurestaticapps.net`.

При повторной публикации достаточно отправить изменения в выбранную GitHub-ветку.

## Публикация через AWS Amplify Hosting

1. Создайте репозиторий на GitHub и загрузите файлы проекта в корень.
2. В AWS Console откройте **AWS Amplify** → **Host web app**.
3. Подключите GitHub, выберите репозиторий и ветку.
4. Для статического HTML-проекта оставьте команды сборки пустыми. Если консоль предлагает `amplify.yml`, используйте:

   ```yaml
   version: 1
   frontend:
     phases:
       build:
         commands: []
     artifacts:
       baseDirectory: /
       files:
         - '**/*'
     cache:
       paths: []
   ```

5. Сохраните настройки и дождитесь публикации. Откройте публичный адрес вида `https://<branch>.<app-id>.amplifyapp.com`.

## Логика теста

Каждый ответ начисляет один балл одной из категорий: `mountains`, `sea`, `forest` или `city`. Дополнительно учитываются две шкалы: социальность (`social`) и активность (`activity`). Основная категория определяет туристическое направление; дополнительные шкалы влияют на название архетипа и формулировку ритма путешествия. При равенстве баллов используется последний выбранный ответ среди категорий-лидеров.

> Иллюстрации локаций в проекте сделаны в оригинальном SVG-стиле. Это локальные файлы проекта, а не фотографии из фотобанка.
